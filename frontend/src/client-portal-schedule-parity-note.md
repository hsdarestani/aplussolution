# Client calendar mobile parity

The customer mobile calendar intentionally has no `Alle / Besetzt / Offen` mode selector. It always renders every non-cancelled shift already scoped to the authenticated customer by the API.

Its rows intentionally follow the Admin/Mitarbeiter Dienstplan visual hierarchy: white row surface, short client accent, worker avatar/name, time on the right, position/location secondary line, shared week strip/day headers, and shared total-hours bar.
