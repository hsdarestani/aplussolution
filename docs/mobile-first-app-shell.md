# Mobile-first app shell

The authenticated frontend uses an app-style responsive shell below 900 px.

- Fixed safe-area-aware app bar
- Bottom navigation for Start, Plan, Zeit, Chat and Mehr
- Role-aware bottom sheet for secondary modules, profile and logout
- Touch targets of at least 44 px
- Responsive cards, forms, messages, modals and Steuerzentrale metrics
- Desktop sidebar remains active above the mobile breakpoint

The layout is designed to remain compatible with the Ionic/Capacitor mobile build.
