# OAuth branding notes

Production social login must follow provider branding requirements.

- Google: use the official Sign in with Google button / approved brand assets and keep it at least as prominent as other third-party sign-in options.
- Apple: use a system-provided Sign in with Apple button where possible, or an Apple-approved web button that follows the Human Interface Guidelines.
- A+ Solution social login never creates a public account. It only authenticates portal accounts already created or invited by A+ Solution.
