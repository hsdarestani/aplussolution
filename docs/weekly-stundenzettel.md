# Weekly Stundenzettel

Web admin dashboard: Stundenzettel → Kalenderwoche → Housekeeping · PDF / Front Office · PDF. Hidden in Capacitor builds. Server enforces existing admin/manager permissions; employee/client/anonymous access is denied.

GET `/api/reports/stundenzettel.pdf?week=2026-W45&group=housekeeping` (or `front_office`). Strict ISO week validation; weeks run Monday–Sunday in Europe/Berlin. Default selection is the last completed Berlin week. No email is sent.

The background is the actual emailed A+ form (Gmail Front Office editable attachment, 5 October 2026), with all original form widgets and example personal/hotel data removed, and the department/hotel fields cleared. Both department variants share this print layout and logo. The original 15-row landscape A4 form remains editable with unique fields per page.

Uses every non-cancelled Shift and its active slot cards from the Dienstplan. Planned start/end and planned breaks are authoritative; attendance records, clock status, approval and employee confirmation do not filter or override the export. Each assigned/open card is a row, including pending assignments and shifts with no time entry. A cancelled slot is excluded and stale Shift.worker mirrors are not resurrected. Historical shifts without slot rows use direct assignment/capacity fallback. Unfilled places are explicitly named OpenShift. No live WIW API calls or database writes.

Entries belong to their Berlin start date, including overnight/week-boundary shifts (as in the emailed FO example). Duration uses the entire planned UTC elapsed interval, with NO break deduction, including night shifts and DST transitions. Legal first/last names are used, not display aliases. Each client/location has separate pages, even when names match; 14 entries plus the numeric page sum in the hours column, exactly as the emailed form. The sum is computed from the displayed decimal-hour values to avoid discrepancies with the visible rows. Hotel, department, every row field and the numeric sum are all editable AcroForm fields. Start, end and hours changes recalculate the row and page total in Acrobat/Reader (where PDF JavaScript is enabled); other PDF viewers may not execute these scripts, but still allow manual editing of all fields. The upper-right area is empty and the sum has no caption. Per the owner’s explicit format instruction, each populated work row displays “bestätigt” under the original “Bestätigung Hotel (Unterschrift)” heading. This export wording does not update approval/signature records in the database.

Validation: backend tests cover permissions, invalid ISO weeks, empty schedule, planned hours/break deduction, overnight week boundary, missing/pending/conflicting attendance, active slot cards, editable fields/appearances, hotel isolation, multipage rendering and DST. Frontend tests cover native hiding, ISO week-year/Berlin boundaries, selected week/group download and failures. Build and PDF render inspection required before release.
